# Direção visual do curso

## Referência de composição

A interface adota uma linguagem de landing page editorial para cursos técnicos:
hero em duas colunas, narrativa clara, terminal visual, blocos alternados de
contexto e ementa extensa em cards numerados. As referências recebidas orientam
composição, densidade, contraste e ritmo — não textos, marcas, cores ou ativos
de terceiros.

## Sistema visual

- Fundo: azul-noite quase preto, com grade técnica de baixa opacidade.
- Luz: ciano elétrico e azul-neon em halos contidos; verde apenas para sucesso.
- Tipografia: sans limpa para leitura e monoespaçada para comandos, estados e
  metadados.
- Superfícies: cartões azul-escuros, cantos arredondados e bordas finas.
- Hierarquia: títulos grandes e editoriais; texto curto e legível; ementa
  detalhada sem comprimir unidades.
- Mini pets: marca original de cada trilha, criada como elemento vetorial do
  curso, nunca como emoji.

## Regras de preservação

Esta direção visual é compatível com o mapa canônico, mas não altera seu escopo
pedagógico. Mudanças futuras em identidade, layout, cores ou interação devem
ser apresentadas como proposta visual antes de substituir esta base.
