# Rubrica — Preparação do ambiente

## Uso

Esta rubrica confere se existe base suficiente para iniciar B1 com segurança.
Ela não audita uma conta, não confirma elegibilidade para recursos e não
substitui as políticas de uma organização.

| Critério | Evidência suficiente | Ainda incompleto |
| --- | --- | --- |
| Acesso | Tipo de conta ou workspace identificado. | Acesso presumido, sem confirmação. |
| Disponibilidade | Local de verificação e ao menos uma limitação registrados. | Plano ou recurso tratados como garantidos. |
| Workspace | Pelo menos um ambiente de trabalho escolhido. | Ambiente apenas desejado, sem seleção. |
| Repositório | Repositório, pasta ou fluxo de exercícios indicado. | Sem local de trabalho recuperável. |
| Dados | Limites de compartilhamento definidos sem expor segredos. | Política vaga ou segredo registrado. |
| Revisão | Controles selecionados e revisão antes de ação com impacto descrita. | Ação ou publicação sem revisão prevista. |
| Evidência | Local de registro definido para o checklist. | Conclusão sem registro recuperável. |

## Critério de conclusão

Conclua quando os sete critérios tiverem evidência suficiente. Se o acesso ou
uma capacidade ainda não estiver disponível, registre essa condição e avance
apenas com o caminho que permanece seguro; não contorne permissões.

## Limite pedagógico

O checklist organiza uma decisão de trabalho. Ele não cria conta, muda plano,
instala aplicativo, concede permissão, armazena segredo ou executa ação em
nome do participante.
