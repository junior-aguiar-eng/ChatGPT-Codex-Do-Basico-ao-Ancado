# Rubrica — Diagnóstico inicial

## Uso

Esta rubrica verifica a utilidade do registro de partida. Ela não classifica
inteligência, valor pessoal ou potencial técnico; indica apenas se a próxima
unidade terá contexto suficiente para preparar o ambiente.

| Critério | Evidência suficiente | Ainda incompleto |
| --- | --- | --- |
| Objetivo | Resultado observável e motivo de uso descritos. | Desejo genérico sem resultado esperado. |
| Rota | Uma das três rotas é escolhida como predominante. | Rotas listadas sem prioridade. |
| Repertório | Nível declarado com um exemplo curto do que já é possível fazer. | Apenas rótulo de nível. |
| Ambiente | Pelo menos um ambiente disponível é identificado. | Nenhum ambiente selecionado. |
| Projeto | Há problema ou rotina de referência, sem expor conteúdo confidencial. | Projeto abstrato ou dado sensível exposto. |
| Cuidados | Ao menos um risco e um controle inicial são registrados. | Riscos relevantes ignorados. |
| Sucesso | Critério pessoal verificável ao final do curso. | Fórmula vaga, sem evidência de êxito. |

## Critério de conclusão

O diagnóstico está concluído quando os sete critérios tiverem evidência
suficiente. Caso um deles falte, complete apenas o campo correspondente antes
de avançar para a Preparação do ambiente.

## Limite pedagógico

As respostas apontam necessidades de aprendizagem; não substituem avaliação de
segurança, aconselhamento profissional ou decisão de acesso a produto.
