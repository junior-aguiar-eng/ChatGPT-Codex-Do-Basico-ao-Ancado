# Diagnóstico inicial

## Missão de entrada

Registrar o ponto de partida do participante antes de qualquer escolha de
ferramenta. Esta unidade não mede valor pessoal nem exige experiência técnica;
ela produz um retrato útil para orientar o percurso.

## Perguntas de diagnóstico

1. Qual resultado você quer alcançar com o curso?
2. Qual é seu repertório atual com ChatGPT, programação, Git e APIs?
3. Em que ambiente você trabalha: navegador, desktop, IDE, terminal ou nuvem?
4. Qual projeto real você gostaria de melhorar ou construir?
5. Quais dados, pessoas, prazos ou custos exigem cuidado desde o início?

## Entrega

Crie um registro com objetivo, contexto, projeto de referência, limitações e
critério pessoal de sucesso. A próxima unidade usa esse registro para preparar
o ambiente e os controles de dados.
