# Instruções do repositório

## Fonte de verdade

- O GitHub é a fonte de verdade do projeto.
- Trabalhos relevantes devem ter escopo explícito, histórico de Git e revisão
  proporcional ao risco.
- Não incluir segredos, dados pessoais ou chaves de API no repositório.

## Conteúdo educacional

- Diferenciar fato documentado, inferência pedagógica e hipótese.
- Ao descrever uma capacidade da OpenAI, indicar fonte oficial e data de
  verificação em `docs/fontes.md` ou no próprio material.
- Declarar quando uma capacidade depende de plano, região, plataforma,
  permissões ou disponibilidade.
- Todo laboratório deve ser reproduzível e conter critérios de conclusão.

## Qualidade

- Atualizar a documentação canônica junto com qualquer mudança de currículo,
  comportamento, versão ou publicação.
- Revisar links, exemplos e consistência entre módulos antes de publicar.
